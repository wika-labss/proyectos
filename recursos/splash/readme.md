# Splash

Pantallas de inicio, splash screens y assets de carga inicial.

## Formatos permitidos

- **PNG** — transparencia y compatibilidad universal para splash nativos
- **WebP** — alternativa comprimida cuando la plataforma lo soporte
- **SVG** — solo para logos o elementos vectoriales del splash

## Convención de nombres

Usa `kebab-case`: `splash-logo.png`, `splash-background.webp`, `launch-icon.svg`.

## Antes de subir

Comprime PNG/WebP con [TinyPNG](https://tinypng.com/) y optimiza SVG con [SVGOMG](https://jakearchibald.github.io/svgomg/) antes de subir.
