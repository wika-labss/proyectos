## Buenas Prácticas

- **Convención de nombres:** usa `kebab-case` para todos los archivos (ej. `home-background.webp`, `primary-button.svg`).
- **Compresión previa:** optimiza las imágenes antes de subirlas. Herramientas recomendadas: [TinyPNG](https://tinypng.com/) para PNG/WebP y [SVGOMG](https://jakearchibald.github.io/svgomg/) para SVG.
- **Formatos vectoriales:** prefiere `.svg` cuando el recurso sea escalable (iconos, botones, ilustraciones simples). Reserva PNG/WebP para fondos, splash y assets rasterizados.
