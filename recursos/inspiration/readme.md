# Inspiration

Carpetas **independientes** de arte de inspiración por juego o escena.
No es el catálogo genérico de `backgrounds/`. Cada subcarpeta es un pack propio.

## Convención

- Una carpeta por pack (`kebab-case`).
- El runtime copia a `iterations/vN/assets/recursos/inspiration/{pack}/`.
- Metro no importa desde este catálogo.
