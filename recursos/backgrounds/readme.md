# Backgrounds

Fondos, texturas y capas de ambiente para pantallas y secciones.

## Formatos permitidos

- **WebP** (preferido) — buena compresión con transparencia opcional
- **PNG** — cuando se requiera compatibilidad amplia o transparencia
- **JPG** — solo para fotografías sin transparencia

## Convención de nombres

Usa `kebab-case`: `home-background.webp`, `login-gradient.png`, `menu-texture.webp`.

## Antes de subir

Comprime y optimiza las imágenes (ej. [TinyPNG](https://tinypng.com/)) para reducir peso sin perder calidad perceptible.
