# Templates

Plantillas reutilizables de diseño, layouts base y assets de referencia.

## Formatos permitidos

- **SVG** (preferido) — plantillas vectoriales editables y escalables
- **PNG** — capturas o mockups rasterizados de referencia
- **WebP** — alternativa comprimida para previews y thumbnails

## Convención de nombres

Usa `kebab-case`: `card-template.svg`, `screen-layout-mobile.png`, `component-preview.webp`.

## Antes de subir

Optimiza SVG con [SVGOMG](https://jakearchibald.github.io/svgomg/) y comprime PNG/WebP con [TinyPNG](https://tinypng.com/) antes de versionar.
