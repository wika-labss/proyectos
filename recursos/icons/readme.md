# Icons

Iconografía de navegación, acciones y estados de la aplicación.

## Formatos permitidos

- **SVG** (preferido) — ideal para iconos escalables en cualquier densidad
- **PNG** — solo cuando el icono requiera detalle rasterizado o efectos no vectoriales

## Convención de nombres

Usa `kebab-case`: `home-icon.svg`, `settings-icon.svg`, `chevron-right.png`.

## Antes de subir

Optimiza SVG con [SVGOMG](https://jakearchibald.github.io/svgomg/) y comprime PNG con [TinyPNG](https://tinypng.com/) para mantener el repositorio liviano.
