# Buttons

Botones, estados hover/pressed/disabled y controles táctiles.

## Formatos permitidos

- **SVG** (preferido) — escalable y ligero para formas simples
- **PNG** — para botones con efectos rasterizados o sombras complejas
- **WebP** — alternativa comprimida a PNG cuando no aplique SVG

## Convención de nombres

Usa `kebab-case`: `primary-button.svg`, `secondary-button-pressed.png`, `fab-icon.svg`.

## Antes de subir

Optimiza SVG con [SVGOMG](https://jakearchibald.github.io/svgomg/) y comprime PNG/WebP con [TinyPNG](https://tinypng.com/) antes de agregar al repositorio.
