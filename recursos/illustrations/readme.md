# Illustrations

Ilustraciones decorativas, empty states, onboarding y gráficos de apoyo.

## Formatos permitidos

- **SVG** (preferido) — ilustraciones vectoriales escalables
- **WebP** — ilustraciones rasterizadas con buena compresión
- **PNG** — cuando se requiera transparencia y compatibilidad amplia

## Convención de nombres

Usa `kebab-case`: `empty-state.svg`, `onboarding-step-1.webp`, `welcome-hero.png`.

## Antes de subir

Optimiza SVG con [SVGOMG](https://jakearchibald.github.io/svgomg/) y comprime PNG/WebP con [TinyPNG](https://tinypng.com/) para evitar archivos pesados en el repo.
