# Audio

Loops y efectos de sonido del catálogo WIKA.

## Convención

- Nombres en `kebab-case`.
- Un loop ambiental por juego cuando aplique.
- El runtime de cada app **copia** el archivo a `iterations/vN/assets/recursos/audio/` (Metro no importa desde este catálogo).

## Catálogo

| Archivo | Tema | Destino runtime |
|---------|------|-----------------|
| `arkanoid-ambient-loop.mp3` | Nebula | `app/arkanoid/iterations/v3/assets/recursos/audio/ambient-loop.mp3` |
| `arkanoid-ambient-castle.mp3` | Castillo | `app/arkanoid/iterations/v3/assets/recursos/audio/ambient-castle.mp3` |
