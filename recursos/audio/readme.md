# Audio

Loops y efectos de sonido del catálogo WIKA.

## Convención

- Nombres en `kebab-case`.
- Un loop ambiental por juego cuando aplique.
- El runtime de cada app **copia** el archivo a `iterations/vN/assets/recursos/audio/` (Metro no importa desde este catálogo).

## Catálogo

| Archivo | Uso | Destino runtime |
|---------|-----|-----------------|
| `arkanoid-ambient-loop.mp3` | Loop ambiental Arkanoid (menú + partida) | `app/arkanoid/iterations/v3/assets/recursos/audio/ambient-loop.mp3` |
