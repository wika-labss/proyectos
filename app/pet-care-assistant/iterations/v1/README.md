# Pet Care Assistant — iterations/v1

App Android offline (Expo SDK 52) para registrar el cuidado diario de mascotas.

## Features V1

- Ficha (tipo, edad, sexo, peso) y multi-mascota
- Comidas, baño + consistencia de heces, paseos, notas
- Salud (sano / enfermo / recuperación)
- Histórico por fecha
- Vacunas y desparasitación (aviso visual)
- Persistencia local AsyncStorage
- Package: `com.wika.petcareassistant`

## Scripts

```bash
npm install
npm run smoke
npm run typecheck
npm run verify   # requiere JDK 17 + Android SDK
npm run apk
```
