# V3 — Sodoku nuevo

## Resumen
Extiende V2 con **100 niveles**, sistema de **recompensas** (`regalo 1`…`regalo 8`), **inventario** (solo visualización), home con botones **Jugar / Inventario** + info (**Puntaje / Histórico / Regalos**), y diseño **Pinki Cute** desde `imagenes/`.

## Cambios vs V2

| Área | V2 | V3 |
|------|----|----|
| Niveles | 20 | **100** |
| Dificultad | no alternada documentada | easy/medium **interna** alternada; **oculta** al jugador |
| Recompensas | no | aleatorio `regalo 1`…`regalo 8` al completar |
| Inventario | no | lista de regalos ganados (view-only) |
| Home | score / history / completed | **Jugar**, **Inventario**, **Puntaje**, **Histórico**, **Regalos** |
| Visual | blanco/negro | Pinki Cute (`imagenes/`) |
