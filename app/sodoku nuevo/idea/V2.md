# Documentación V2 — Sodoku nuevo

## Resumen

Iteración V2 corrige el motor de puzzles (solución única obligatoria), agrega 3 pistas por nivel y enriquece la pantalla principal con puntaje, histórico local y niveles completados.

## Documentos idea/ actualizados

- `01-problem.md`
- `02-features.md` — Features 11–13 V2
- `03-module-discovery.md` — módulo `hints` + home progreso
- `04-application-design.md`
- `05-build-plan.md` — orden: validar motor → UI

## Hallazgo V1

El generador tenía un **fallback** que podía entregar puzzles sin solución única. V2 lo elimina y exige `validatePuzzle`.
