# Alvaro Snake — iterations/v1

Expo SDK 52 · React Native · Android package `com.wika.alvaro`

## Reglas V1

- Crece +1 por pelotita
- 3 vidas
- Score = tiempo vivo × 10
- High score local (`alvaro:v1:highScore`)

## Scripts

| Comando | Uso |
|---------|-----|
| `npm start` | Metro / Expo Go |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run smoke` | Gates del motor puro |
| `npm run verify` | Gates WIKA + APK Release (JDK 17 + Android SDK) |
| `npm run apk` | Solo APK Release |

## Build APK

Ver `BUILD-APK.md`. Requiere **JDK 17** y Android SDK.
