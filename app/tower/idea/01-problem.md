# Problema

## Nombre del proyecto

Tower

## Descripción

Tower Defense Android offline. **V4** sube un poco la dificultad respecto a V3 (sin romper fusión L1–L4 ni economía base), añade **venta de torres** con reembolso parcial (~70% del oro invertido, incl. evoluciones), **modo infinito** con dificultad escalable, y una **tienda visual** (sin IAP real aún) para Modo Infinito y Pack de Contenido (10 mapas, torres nuevas, hardcore).

## Objetivo

Entregar V4 (APK Release) con: dificultad ligeramente mayor, sell/refund, infinite mode jugable, shop UI stub sin cobros.

## Criterios de éxito

- [x] Campaña un poco más difícil que V3, aún pasable.
- [x] Vender torre → +floor(oroInvertido×0.7), libera pad.
- [x] Shop muestra Infinito + Pack; botón Comprar no cobra (mensaje “próximamente”).
- [x] Modo infinito con oleadas que escalan.
- [x] Pack: preview visual (mapas/torres/hardcore) bloqueado hasta compra futura.
