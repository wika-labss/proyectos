# Preview compartible — Tower v5

Maqueta web (marco de teléfono) para revisar Ember Keep **antes** de generar APK.

## Abrir

```text
proyectos/app/tower/iterations/v5/preview/index.html
```

Sirve la carpeta (`python3 -m http.server`) o ábrela en el navegador. Pestañas: Menú · Partida · Tienda · Victoria.

## Share estático

- `share-game.png` — ilustración de partida
- `capture-menu.webp` / `capture-partida.webp` — capturas del HTML

No es el binario Android. APK = `npm run apk:win` en v5, solo si lo pides.
