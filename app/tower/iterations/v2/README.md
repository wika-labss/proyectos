# Tower Defense — iterations/v2

Expo SDK 52 · React Native · Android package `com.wika.tower`

## Cambios V2

- 25 niveles / mapas distintos
- Contrato de alcance: todos los pads alcanzables por las 4 torres
- Fase **preparación** antes de oleadas
- Colocación antes / entre / durante oleadas
- Torres con forma + etiqueta (Arq / Cañ / Hie / Fra)
