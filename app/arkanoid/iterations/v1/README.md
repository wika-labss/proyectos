# Arkanoid V1 — Expo SDK 52

Juego Arkanoid / Breakout offline (Android).

- Menú futurista · partida retro
- Reglas clásicas: pala, bola, ladrillos, 3 vidas, 3 niveles
- High score local (`arkanoid:v1:highScore`)
- Package: `com.wika.arkanoid`

## Dev

```bash
npm install
npm run smoke
npm run typecheck
npm start
```
