# Flujo WIKA — Arkanoid V4

```
Idea / Preparación (idea/ 01–05, Feature 24 retirada)
    → Auditoría 1
         documentación  → auditoria-documentacion-v4.md  APROBADO
         módulos        → auditoria-modulos-v4.md        APROBADO
         ensamblado     → auditoria-ensamblado-v4.md     APROBADO
    → Generación IA (iterations/v4)
    → Auditoría 2
         auditoria-release-v4.md  REQUIERE CORRECCIONES (sideload)
    → Aprobación / final/     ← bloqueado
```

`idea/` es la única fuente de verdad. No se copia a `iterations/` ni a `final/`.

V3 (`iterations/v3`) conserva el MP3 Castillo. V4 no lo empaqueta.
